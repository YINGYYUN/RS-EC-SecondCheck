### 一、项目文件说明
| 文件名称               | 功能描述                                                                 |
| :--------------------- | :----------------------------------------------------------------------- |
| A、B、C                | 直接对应考核的 A、B、C 三项基础任务                                       |
| D1、E1                 | 早期开发版本：使用 BMP 库解算 MPU6050，未实现快速刷新解算方法（本人暂未掌握该方案） |
| D2、E2                 | 后期优化版本：采用互补滤波解算 MPU6050，功能完备、稳定性提升               |
| ComplementaryFilter    | 互补滤波模板文件（可复用至其他 MPU6050 姿态解算场景）                     |
| MENU_TeatProject       | 考核任务菜单化整合版本（统一调用 A/B/C/D/E 所有任务，方便测试）             |
| 引脚分配               | 详见具体项目文件夹内的硬件连接说明                                         |
